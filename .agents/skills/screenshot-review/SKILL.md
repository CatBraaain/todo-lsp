# Screenshot Review

## 進め方

1. `just screenshot` を実行し、出力先 `screenshots/<YYYYMMDD-HHMMSS>/` を特定する。終了コード 0 で、撮影対象表に挙げられた全 PNG が出力先へ揃ったことを確認する
2. SPEC.md §スクショ の撮影対象表を読み、PNG ごとの期待（「画面の状態」と「確認する節」）を抽出する。SPEC を唯一の情報源とし、期待の内容を本 skill に複製しない
3. PNG 1 枚につき vision subagent を 1 回起動する。依頼文には次を含める:
   - PNG の絶対パス
   - 期待する画面の状態（撮影対象表の「画面の状態」と、確認する節の要点）
   - 報告形式: 期待ごとの適合/不適合と、根拠となる観察をテキストで報告すること
4. 全件の報告を統合し、owner へ適合/不適合の一覧で報告する。不適合には根拠となる観察を添え、該当する SPEC の節を示す

## 判定の範囲

vision モデルは flash クラスのため、期待は構造レベル（アウトラインの有無、パネルの表示、折りたたみの効き、灰色行の有無など）で書く。色相の一致までは判定させず、色の確認は owner の目視に委ねる。
